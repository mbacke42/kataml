# KataML

*Keen-edged Analytics Toolkit for Applied Machine Learning.*

KataML is a visual machine learning workbench: you connect nodes on a canvas (data,
preparation, models, evaluation, charts), configure and run them, then export everything to
a Python script or a Jupyter notebook. Computations rely on
[scikit-learn](https://scikit-learn.org) and [pandas](https://pandas.pydata.org).

Built by **Claude Opus 5.5**, led by **Frédéric Blanchard**.
