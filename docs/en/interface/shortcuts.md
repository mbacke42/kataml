# Shortcuts

Shortcuts work when the cursor is not in an input field. On macOS, ++ctrl++ means ++cmd++.

## Execution

| Shortcut | Action |
|---|---|
| ++f7++ | run the selection (and what precedes it) |
| ++shift+f7++ | run all |
| ++f8++ | reset the selection (and its descendants) |

## Editing

| Shortcut | Action |
|---|---|
| ++ctrl+z++ / ++ctrl+y++ (or ++ctrl+shift+z++) | undo / redo |
| ++ctrl+c++ / ++ctrl+v++ | copy / paste |
| ++ctrl+d++ | duplicate |
| ++ctrl+a++ | select all |
| ++delete++ or ++backspace++ | delete the selection or the selected connection |
| ++escape++ | deselect, close a dialog |
| ++ctrl+g++ | group the selection as a component |
| ++a++ | new annotation |
| ++l++ | arrange automatically |

## Files and tools

| Shortcut | Action |
|---|---|
| ++ctrl+s++ | save |
| ++ctrl+shift+s++ | save as |
| ++ctrl+p++ | generate a report |
| ++f1++ | help |

## Navigation

| Gesture | Action |
|---|---|
| wheel, pinch | zoom |
| drag the background, middle click, ++space++ + drag | pan |
| ++plus++ / ++minus++ | zoom in / out |
| ++f++ | fit to screen |
| double-click on the background | quick add a node |
| ++shift++ + drag | rectangle selection |
| ++alt++ + drag a node | move without the grid |

## In code editors

| Shortcut | Action |
|---|---|
| ++tab++ | insert four spaces |
| ++ctrl+s++ | save and reload (block editor) |
