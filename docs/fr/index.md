# KataML

*Keen-edged Analytics Toolkit for Applied Machine Learning.*

KataML est un atelier visuel de machine learning : on relie des nœuds sur un canevas
(données, préparation, modèles, évaluation, graphiques), on les configure et on les exécute,
puis on exporte le tout en script Python ou en notebook Jupyter. Les calculs reposent sur
[scikit-learn](https://scikit-learn.org) et [pandas](https://pandas.pydata.org).

Développé par **Claude Opus 5.5**, piloté par **Frédéric Blanchard**.
