# Raccourcis

Les raccourcis agissent quand le curseur n'est pas dans un champ de saisie. Sur macOS,
++ctrl++ correspond à ++cmd++.

## Exécution

| Raccourci | Action |
|---|---|
| ++f7++ | exécuter la sélection (et ce qui la précède) |
| ++shift+f7++ | tout exécuter |
| ++f8++ | réinitialiser la sélection (et ses descendants) |

## Édition

| Raccourci | Action |
|---|---|
| ++ctrl+z++ / ++ctrl+y++ (ou ++ctrl+shift+z++) | annuler / rétablir |
| ++ctrl+c++ / ++ctrl+v++ | copier / coller |
| ++ctrl+d++ | dupliquer |
| ++ctrl+a++ | tout sélectionner |
| ++delete++ ou ++backspace++ | supprimer la sélection ou la connexion sélectionnée |
| ++escape++ | désélectionner, fermer une boîte de dialogue |
| ++ctrl+g++ | grouper la sélection en composant |
| ++a++ | nouvelle annotation |
| ++l++ | organiser automatiquement |

## Fichiers et outils

| Raccourci | Action |
|---|---|
| ++ctrl+s++ | enregistrer |
| ++ctrl+shift+s++ | enregistrer sous |
| ++ctrl+p++ | générer un rapport |
| ++f1++ | aide |

## Navigation

| Geste | Action |
|---|---|
| molette, pincement | zoomer |
| glisser le fond, clic molette, ++space++ + glisser | se déplacer |
| ++plus++ / ++minus++ | zoom avant / arrière |
| ++f++ | ajuster à l'écran |
| double-clic sur le fond | ajout rapide d'un nœud |
| ++shift++ + glisser | sélection rectangulaire |
| ++alt++ + glisser un nœud | déplacer sans grille |

## Dans les éditeurs de code

| Raccourci | Action |
|---|---|
| ++tab++ | insérer quatre espaces |
| ++ctrl+s++ | enregistrer et recharger (éditeur de blocs) |
